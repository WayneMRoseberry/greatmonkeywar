# greatmonkeywar
Great Monkey War game project

## For designers and artists

You can change levels, characters, cut scenes, and art without writing code. Start here:

- [Building levels](docs/guide-levels.md): start with this one. It includes a five-minute introduction to the JSON files the game uses, and how to see your changes in the game.
- [Characters and objects](docs/guide-characters-objects.md): the hero, enemies, and objects the hero can pick up.
- [Cut scenes](docs/guide-cutscenes.md): the scenes that play between levels.
- [Sprites and animation](docs/guide-sprites.md): getting animated art into the game.

## For developers

See the [developer guide](docs/developer-guide.md) for setup, running the game, and tests.
